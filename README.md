# Компас заботы

Бесплатный дневник наблюдений за близким человеком: события, артериальное давление, сахар, приёмы лекарств и отчёты для врача. Работает прямо в браузере телефона или компьютера.

**Открыть приложение:** <https://andreygrinover-hash.github.io/care-compass/>

## Что умеет

- **Свои события** — любые пункты наблюдения (туалет, падения, прогулки, настроение и другие), отмечаются в один тап, ведётся статистика «сколько раз за день».
- **Давление и сахар** — дневник с графиком за выбранный период и целевыми значениями.
- **Лекарства** — расписание по слотам (утро, день, вечер, ночь), общий список препаратов, журнал приёмов, отметка одним касанием, время отметки можно поправить.
- **Напоминания** — файл календаря `.ics`: события «Пора принимать лекарства» добавляются в календарь телефона и повторяются каждый день. Часы настраиваются в приложении (вкладка «Данные» → «Напоминания о приёме»).
- **Отчёт для врача** — сводка за период с таблицей, графиком и журналом изменений: печать из браузера в PDF, бесплатно.
- **Резервные копии** — автоматический снимок раз в сутки (хранятся 14 последних), отправка копии в мессенджер или почту, импорт/экспорт JSON и CSV.
- **Несколько пациентов** — можно вести дневники наблюдения отдельно для каждого подопечного.
- **Крупный шрифт и тёмная тема**, интерфейс на русском, без регистрации.

## Как установить на телефон

1. Откройте ссылку сайта в браузере (Chrome или Яндекс Браузер).
2. Меню браузера → **«Добавить на главный экран»** (или «Установить приложение»).
3. Готово: иконка на рабочем столе, приложение работает офлайн, данные — только на телефоне.

## Приватность

Все данные хранятся только на вашем устройстве (localStorage браузера). Сайт не имеет серверной части, не собирает и не передаёт никаких данных — он отдаёт только статические файлы. Интернет нужен лишь один раз, чтобы открыть сайт в первый раз.

## Синхронизация между устройствами

Автоматической синхронизации нет — это осознанное решение ради приватности. Перенести данные между телефонами можно резервной копией (JSON) или файлом CSV.

## Важно

Приложение — личный дневник наблюдений, а не медицинское изделие. Оно не заменяет консультацию врача, не ставит диагнозы и не проверяет совместимость препаратов.
